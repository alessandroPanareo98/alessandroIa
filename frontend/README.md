# Frontend - AI DevOps Assistant

Frontend Angular 20 con routing, dashboard, grafici Chart.js e pagine operative per pipeline, errori, analisi e notifiche.

## Avvio
1. Installa dipendenze:
   npm install
2. Avvia in sviluppo:
   npm start
3. Build produzione:
   npm run build

## Routing
- /dashboard
- /pipelines
- /errors
- /analyses
- /notifications
- /settings

## Integrazione API
Base URL configurato in:
- src/environments/environment.ts
- src/environments/environment.prod.ts
